# Web interface: polish and identity

Objective: polish the single view of `knit ui`: blocks with their own identity (not phone-shaped), an inline quick-access expansion per block, a modal instead of the side panel, prompt routing to the orchestrator, and a Cursor view that shows reasoning and changes live. Delivered as PRs #31 to #33, all merged into `main` (the work branches were deleted). Delivery: sequential, inline, no parallel agents (user: "Vamos de a poco sin levantar agentes en paralelo para optimizar los tokens"); one branch per task, stacked PRs, no AI attribution. Test runner: vitest (`pnpm test`), plus `pnpm typecheck` and `pnpm build`.
